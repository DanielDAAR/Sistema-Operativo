## Nuestras Herramientas

### Desarrollo y Código
- **GitHub** — Control de versiones, repositorios, trabajo en equipo
- **VS Code** — Editor de código principal

### Hosting y Despliegue
- **Netlify** — Hosting gratuito para páginas web estáticas
  - SSL incluido
  - Despliegue automático desde GitHub
  - Dominios personalizados
  - Velocidad excelente

### Bases de Datos y Backend
- **Supabase** — Base de datos PostgreSQL, autenticación, almacenamiento
  - Base de datos en tiempo real
  - Autenticación de usuarios
  - Almacenamiento de archivos
  - API automática

### Dominios
- **Namecheap** — Compra de dominios a bajo costo
  - Dominios .com desde ~$150 MXN/año
  - DNS management
  - Privacidad de WHOIS incluida

- **Figma** — Diseño de interfaces (si aplica)
