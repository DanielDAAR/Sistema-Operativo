## CUÁNDO USAR SUPABASE

Supabase es para proyectos que necesitan:
- Base de datos de productos
- Login de usuarios
- Formularios avanzados
- Sistemas de reservación
- Contenido dinámico

**NO usar Supabase para:**
- Páginas web informativas básicas
- Landing pages
- Portafolios simples

**Ejemplo de uso:**
- Tienda en línea con catálogo
- Sistema de reservaciones
- Portal de clientes
- Blog con administración
