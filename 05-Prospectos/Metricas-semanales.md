## RECORDATORIO

**Las métricas sin acción no sirven de nada.**

Cada número debe llevar a una decisión:
- Si no hay respuestas → cambiar el mensaje
- Si no hay reuniones → mejorar el follow-up
- Si no hay cierre → ajustar precio o propuesta
- Si no hay entregas → revisar proceso de desarrollo
