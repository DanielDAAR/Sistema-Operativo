# CHECKLIST DE 5 MINUTOS — Antes de mandar CUALQUIER mensaje

**Este checklist vale más que cualquier mensaje que escribas.**
Un mensaje perfecto desde un perfil vacío se borra. Un mensaje simple desde un perfil real se abre.

---

## ¿POR QUÉ IMPORTA TANTO?

Cuando te llega un mensaje de un número que no conoces, tu cerebro hace esto en menos de 1 segundo:

```
┌─────────────────────────────────────────────┐
│  Veo la notificación:                       │
│                                             │
│  "Hola, una duda rápida..."                 │
│                                             │
│  Pero antes de abrir, MI CEREBRO pregunta:  │
│                                             │
│  → ¿Quién es este?                          │
│  → ¿Tiene foto de perfil?                   │
│  → ¿Qué dice su "Info"?                     │
│                                             │
│  Si las tres respuestas son "nada"...       │
│  → BORRAR. Sin abrir.                       │
└─────────────────────────────────────────────┘
```

**El mensaje es el 50% del resultado. El perfil es el otro 50%.**

## 🎓 CÓMO HACERLO EN WHATSAPP

```
1. Abre WhatsApp
2. Toca tu foto de perfil (arriba a la izquierda)
3. Toca el ícono de cámara → "Galería" → elige logo_DSW.jpg
4. Toca tu nombre (arriba) → bórralo → escribe "D.Softworks" → Guardar
5. Toca los 3 puntitos → Ajustes → "Acerca de" → pega el texto de arriba
6. (Opcional) Toca los 3 puntitos → Estado → pega el texto de la oferta
```

## 💡 POR QUÉ ESTO NO SE SALE EN NINGÚN TUTORIAL DE VENTAS

Porque la mayoría de los que "venden por WhatsApp" ya tienen 500 contactos guardados. Su teléfono está lleno de gente que ya los conoce.

**Esta es la verdadera automatización:**

| Sin perfil configurado | Con perfil configurado |
|---|---|
| "Soy spam, bórralo" | "¿Qué negocio es este?" |
| 1 de cada 100 abre | 1 de cada 3 abre |
| Necesitas 500 mensajes para 5 aperturas | Necesitas 15 para 5 aperturas |

**Es aritmética pura. 500 mensajes fríos = te banean. 15 mensajes a los correctos = te agradecen.**
