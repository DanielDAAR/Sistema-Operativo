## FORMATO DE PUBLICACIÓN

### Para portafolio:
```
[IMAGEN del proyecto]

✅ Proyecto entregado: [Nombre del negocio]

[Qué hicimos] para [nombre del negocio].
[Resultado que obtuvo el cliente].

¿Quieres algo similar para tu negocio? 
Escríbenos: [enlace WhatsApp]

#DSoftworks #DiseñoWeb #NegociosLocales #Guadalajara
```

### Para educativo:
```
[IMAGEN con frase o dato]

[Título del contenido]

[2-3 párrafos explicando]

💡 Consejo: [Acción específica que puede tomar el lector]

¿Necesitas ayuda con esto? Escríbenos.

#DSoftworks #MarketingDigital #NegociosLocales
```
