# D.Softworks — Tono de Voz

## CÓMO HABLAMOS

### Personalidad
- Profesionales pero cercanos
- Resolvemos problemas, no vendemos humo
- Somos directos y honestos
- Tratamos al cliente como persona, no como número

### Tono
- Cercano, no formal excesivo
- Confiable, no arrogante
- Entusiasta, no exagerado
- Simple, no técnico

### Tratamiento
- Usamos "tú" (no "usted")
- Excepción: clientes mayores o muy formales → "usted"

---

## EJEMPLOS

### ❌ NO decir:
- "Somos una empresa líder en soluciones digitales"
- "Contamos con tecnología de vanguardia"
- "Nuestro equipo de expertos"
- "Soluciones integrales sinérgicas"
- "Hable con un asesor"

### ✅ SÍ decir:
- "Creamos páginas web para negocios locales"
- "Te ayudamos a tener presencia en internet"
- "El precio es $1,500 MXN"
- "¿Te gustaría que te mostremos cómo se vería?"
- "Escríbeme y te ayudo"

---

## EMOTICONES

### Usar con moderación:
- 👋 Para saludos
- 🤝 Para despedidas
- ✅ Para listas
- 💡 Para consejos
- ⚠️ Para advertencias
- 📱 Para contactos

### No abusar:
- No usar en cada frase
- No usar los mismos siempre
- No usar emojis raros o confusos

---

## REDES SOCIALES

### Facebook
- Tono más informal
- Publicaciones más visuales
- Responder comentarios rápido
- Usar historias para contenido diario

### Instagram
- Tono visual y directo
- Usar carruseles para explicar
- Stories para contenido detrás de cámaras
- Reels para demostraciones rápidas

### WhatsApp
- Tono personal y directo
- Responder rápido
- Usar audios si es más fácil
- Enviar fotos/capturas cuando sea útil

---

## ERRORES COMUNES A EVITAR

1. **Ser demasiado técnico** — El cliente no entiende "React" ni "hosting"
2. **Ser demasiado vago** — El cliente necesita saber qué recibe
3. **No dar precios** — El cliente quiere saber cuánto cuesta
4. **Prometer de más** — Mejor prometer menos y entregar más
5. **No dar seguimiento** — El cliente se olvida de nosotros
