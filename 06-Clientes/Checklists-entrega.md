# D.Softworks — Checklists de Entrega

## CHECKLIST — Página Web Básica

### ANTES DE ENTREGAR
- [ ] Diseño aprobado por el cliente
- [ ] Contenido proporcionado (texto, fotos)
- [ ] Sitio responsive (se ve bien en celular)
- [ ] Formulario de contacto funcionando
- [ ] Enlace a WhatsApp funcionando
- [ ] Ubicación en mapa visible
- [ ] Redes sociales enlazadas
- [ ] Velocidad de carga aceptable
- [ ] Hosting configurado
- [ ] Dominio apuntando
- [ ] SSL activo (https://)
- [ ] Google Analytics instalado (opcional)

### ENTREGA
- [ ] Credenciales de hosting entregadas
- [ ] Credenciales de dominio entregadas
- [ ] Contraseña de administrador entregada
- [ ] Capacitación básica (5-10 min)
- [ ] Documento de soporte entregado

### DESPUÉS DE ENTREGAR
- [ ] Cobrar saldo pendiente
- [ ] Pedir reseña en Facebook
- [ ] Pedir testimonio
- [ ] Solicitar permiso para portafolio
- [ ] Actualizar hoja de clientes
